Ключ API для подключния к LLM программа берет из файла .env.
Временно используется мой личный ключ deepseek.

Рекомендуется использовать с poetry.
Установка зависимостей:
poetry install

Запуск:
poetry run python main.py

По умолчанию интерфейс Gradio открывается в браузере на loсalhost, порт 7860:
http://127.0.0.1:7860/
